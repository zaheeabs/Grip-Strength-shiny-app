# Grip Strength Calculator

A web app built with R Shiny that predicts grip strength from age, sex,
weight and height, and shows where you rank as a percentile.

🔗 https://zaheerabbas.shinyapps.io/GripStrengthApp/

## What it does
- Predicts dominant , non-dominant and combined grip strength
- Shows your percentile rank compared with the NHANES sample data

## Tools used
R , Shiny , bslib

## Data
NHANES 2013-2014 (US CDC National Health and Nutrition Examination Survey)

## Files
- app.R: the Shiny app
- *.rds: the trained models and the dataset used for percentiles

## Limitations
This is a learning project. The data comes from a US population, so
results may not represent other groups. It is not a medical tool.
